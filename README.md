# CHAOS ORDER 混沌の指令

## 公開
GitHubの新規リポジトリにこのフォルダの中身をアップロード。Renderで New > Web Service、リポジトリを接続し、Runtime Node、Build Command `npm install`、Start Command `npm start`、Free を選択。公開URLと6桁IDを友達に共有。ローカルは Node.js 20以上で `npm start`、http://localhost:3000。

## 遊び方
2〜8人。ホストが作成、他の人は参加して準備、ホストが開始。ソロ練習はタイトルから選択。手引きはいつでも開けるがタイマーは止まらない。スコアモードは3/5/10/15/30分、他はライフ制。ゲームは8系統×5バリエーション、4ラウンドごとにレベル上昇。クリアが出ると条件追加、5ラウンドごとに投票。結果はスクショで共有。

## 初版の制限
HTTPポーリング（450ms）で同期。アクション判定はクライアント側なので信頼できる友達向け。25条件のうち一部は表示のみで効果未実装。迷路は障害物のないグリッド移動、回避の一部は共通挙動。BGMなし、効果音のみ。ページ更新で参加情報を失う。サーバー再起動で全データ消失。Render無料枠の休止・再起動に注意。公開環境でのブラウザ通しテストは未実施。
